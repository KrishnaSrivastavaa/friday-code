# KRYX

**Sense the code. Shape the outcome.**

KRYX is a terminal-based AI coding agent built in Python.

## Features

- Terminal-based interface with a custom KRYX design.
- AI-powered coding assistance.
- Configurable AI provider integration.

*Additional features and documentation are coming soon.*

## Requirements

- Python 3.12 or newer.
- An API key for a supported AI provider, if required by your configuration.

## Installation

```bash
pip install kryx
```

## Usage

```bash
kryx
```

## Configuration

Configure your AI provider and API credentials according to the project's configuration settings. Never commit API keys or other secrets to source control.
